# S5 · 双机端到端验收清单

> 为什么要有这份清单：远程电脑的失败大多是**跨端**的——一端写对了、另一端写岔了，
> 或者只在一台机器上跑永远不触发（中继、降级、权限）。单机测试与源码守卫都替不了
> 「两台真机跑一遍」。本清单按操作顺序排，每项都给**判据**，避免「看着像成功了」。

## 0. 前置

- 两台 **Windows 10/11 x64**，都装同一个安装包（版本号必须一致——协议没做版本协商）。
- 第一轮：同一局域网（同一台路由器下、无 AP 隔离）。
- 第二轮（可后补）：一台插手机热点，测中继路径。
- 两台都**允许防火墙**（首次启动 Windows 会弹「允许访问」；拒绝过的去
  `防火墙 → 允许应用通过` 里把 DeskPanda 的专用/公用网络都勾上）。
- 日志：`%LOCALAPPDATA%\com.pastepanda.deskpanda\logs\`（出问题先存这一份）。

## 3. 剪贴板互通

| # | 操作 | 判据 |
|---|---|---|
| 3.1 | A 复制一段中文 + emoji → 在 A 的会话里「发到对方」 | B 的剪贴板真的是这段内容（在 B 上粘一次验证，不看 toast） |
| 3.2 | B 复制一张图片 → A 拉取 | A 剪贴板里是图片（粘到画图里验证） |
| 3.3 | B 侧剪贴板被别的程序锁住（或 B 拒收） | A 侧出现 toast；**不是**静默成功 |

> 判据 34 的教训：`writeText` 会 resolve 却不写。**只认真实粘贴结果**，不看「✓ 已复制」。

## 4. 文件传输

| # | 操作 | 判据 |
|---|---|---|
| 4.1 | A 发一个 1MB 小文件 → B 同意 | B 的 `下载/DeskPanda 接收/` 里出现同名文件，大小一致 |
| 4.2 | A 发一个 500MB 大文件 | 进度条有速度与剩余时间；完成后校验大小一致 |
| 4.3 | 发 3 个文件，其中一个文件名是长中文（> 60 字） | 3 个都成功；失败那个要给出具体原因（不是「未知错误」） |

| 4.5 | B 改接收目录到 `D:\tmp\rc` 后再收 | 文件落在新目录；设置页显示的默认目录是 `下载/DeskPanda 接收` |
| 4.6 | 从 B 反向取 A 的文件 | 同 4.1 |

## 5. 告知浮层（本次补齐的部分，重点验）

| # | 操作 | 判据 |
|---|---|---|
| 5.1 | 主窗**关掉**（收进托盘），A 申请远程 B | B 屏幕顶缘出现置顶确认卡（**不需要**打开主窗） |
| 5.2 | 浮层出现时把全屏应用（播放器 / 游戏）拉到前台 | 卡片仍在该应用之上 |
| 5.3 | 点击卡片空白处之前先在别的程序里打字 | 打字不被打断（浮层**不抢焦点**） |
| 5.4 | 放着不答等 120s | 卡片自行消失，且给出「已超时」一句明确原因 |
| 5.5 | 拒收 | 卡片消失，A 侧收到明确提示（不是一直转圈） |
| 5.6 | B 正被 A 控制时，C 申请远程 B | B 右下角出现隐私胶囊（不是第二张确认卡），点一下能看到会话状态 |
| 5.7 | 浮层弹出时快捷键 / 任务栏切换 | 浮层不出现在任务栏（`skip_taskbar`） |

## 6. 降级路径

| # | 操作 | 判据 |
|---|---|---|
| 6.1 | 把安装目录下 `ffmpeg\` 改名后重启 | 仍能远程控制（退回家用编码）；设置页那些依赖 FF 的选项给出不可用说明，而不是点了没反应 |
| 6.2 | 关掉硬件加速（若可切） | 软编可跑，画面能看（帧率下降可接受） |
| 6.3 | 拔网线 / 关 Wi-Fi 5s 再恢复 | 会话要么自动恢复，要么给出「已断开」并在 10s 内可重连 |
| 6.4 | B 合盖睡眠再唤醒 | 会话不卡死；B 侧提示可重连 |
| 6.5 | 一台走手机热点（不同网段） | 走中继也能连上；界面上能看出当前是「直连」还是「中继」 |

## 7. 记录（发版前填）

**2026-11-20 首次实测（v0.1.1，release + NSIS）**

| 项 | 值 |
|---|---|
| 安装包（NSIS）体积 | **8.7 MB**（9,075,222 B；含 ffmpeg 运行库压缩后） |
| 安装后目录体积 | **约 33 MB**（exe 27.9 + ffmpeg 5.2） |
| 冷启动到窗口出现 | **约 1.0 s**（进程启动 → `MainWindowHandle` 非 0，本机热态） |
| 空闲常驻内存（主进程） | **46 MB** WorkingSet（WebView2 的独立子进程未计入） |
| 会话中常驻内存（主窗 + 浮层） | 待双机实测填 |

> 体积红线据此定：**安装包 ≤ 15 MB、安装后 ≤ 45 MB**（留 ~35% 余量）。
> 壳子模板那条 15MB「安装后目录」红线对「iroh + ffmpeg + Win32 采集」不可能成立，
> 抄旧数字只会让门禁长期失效——所以红线的口径写成「安装包」。
>
> 复现命令（Git Bash，私钥缺失会产不出 `.sig`）：
> ```bash
> export TAURI_SIGNING_PRIVATE_KEY="$(cat "$HOME/.tauri/deskpanda.key")"
> export TAURI_SIGNING_PRIVATE_KEY_PASSWORD=""
> cd desktop && npm run build
> ```

## 8. 本轮已知缺口（不算失败项）

- **macOS 未交付**：`rc` 整体 `cfg(windows)`，mac 只出壳子。
- **手机端**：设置里「手机装 App」那一行是迁过来的死代码（本仓没有手机端）；
  短码配对仍可用两台电脑互扫。
- **AV1**：需要 ffmpeg 运行库（已随包）；没有时自动退 H264/HEVC。
